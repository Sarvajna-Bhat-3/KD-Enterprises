A modern, high-performance, responsive corporate website built for **KD Enterprises** (Proprietor: **Mihir Gandhi**).

## 🌟 Tech Stack
- **Framework:** Next.js 15 (App Router, Server & Client Components)
- **Language:** TypeScript
- **Styling:** Tailwind CSS + PostCSS
- **Icons:** Lucide React
- **Hosting Target:** Vercel (recommended) / Netlify / Cloudflare / Node Server

---

## 🚀 Getting Started Locally

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the local development server:**
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

4. **Production Build:**
   ```bash
   npm run build
   npm start
   ```

## 🌐 One-Click Free Hosting on Vercel

### Method 1: Via GitHub (Recommended)
1. Push this repository to GitHub:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/kd-enterprises.git
   git branch -M main
   git push -u origin main
   ```
2. Go to [https://vercel.com](https://vercel.com) and log in.
3. Click **"Add New" > "Project"**, then select your `kd-enterprises` repository.
4. Leave all build settings as default (Next.js is auto-detected).
5. Click **"Deploy"**. Your live URL will be ready in under 60 seconds (e.g. `kd-enterprises.vercel.app`).

### Method 2: Via Vercel CLI (Direct from terminal)
```bash
npx vercel
```
Follow the interactive prompts to deploy directly.

---

## 🔗 Connecting a Custom Domain (e.g. `kdenterprises.com` / `kdenterprises.in`)
1. In the Vercel Dashboard, go to **Settings > Domains**.
2. Enter your client's domain name.
3. Follow the DNS instructions (pointing A-Record to `76.76.21.21` or CNAME to `cname.vercel-dns.com`).
4. Vercel automatically issues and renews an official SSL certificate (HTTPS) for free.
